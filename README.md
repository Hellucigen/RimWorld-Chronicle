# RimWorld Chronicle · 环世界编年史提取器

> 把你的 RimWorld 存档(`.rws`)变成一份**能读的编年史素材库**:编年大事记、人物档案、任务剧情线、信件与对话、角色台词速查——让"你玩过的这一局"成为可以翻阅、可以改写、可以讲给别人听的故事。
>
> *Turn a RimWorld savegame (`.rws`) into human-readable chronicles — timeline, characters, questlines, letters and AI-chatter transcripts — the raw material of your colony's story. Pure Python standard library, zero pip dependencies, with a Windows GUI.*

## 为什么需要它

环世界的存档里埋着几十万字的故事:年表、任务、信件、日志,还有装了 RimTalk mod 时 AI 生成的殖民者闲聊。但 `.rws` 是几百 MB 的 XML,肉眼不可读。本项目:

1. **解析**——把存档提取成结构化 JSON(年表/任务/人物/信件/RimTalk);
2. **翻译**——扫描你的游戏目录与 mod,把特质、背景的英文 def 名还原成中文标签(找不到游戏目录自动降级,不影响主流程);
3. **成书**——导出六份 Markdown 素材,可直接当设定集翻阅,也适合作为 AI 写作或自己动笔的"事实台账"。

## 输出什么

```
output/
├── First.json 等         # 每个存档的结构化提取(不含本机路径,分享安全)
├── defs.json             # 特质/背景/基因型 中文词典
└── 00_总览.md            # 战役信息:场景、叙事者、势力、特殊规则
    01_编年史.md          # 按游戏日期的大事记(建寨/婚姻/死亡/袭击/任务)
    02_人物档案.md        # 在世/已故/机械体,含背景、特质、关系、伤病
    03_任务剧情线.md      # 全部任务按 mod 阵营主线分组,多存档重复自动标注
    04_信件与对话.md      # 存档窗口内信件全文 + 剧情对话 + RimTalk 台词
    05_角色台词速查.md    # 按说话者聚合全部台词:口吻、出场分布、常对话对象
```

## 快速开始

**GUI(推荐)** —— Windows,无需安装任何依赖:

```bash
python app.py
```

```
┌──────────────────────────────────────────────────┐
│ ① 存档文件(.rws,按游玩先后添加;可多选)         │
│    [ 存档A.rws ▸ 存档B(中期档) ▸ 存档C(终局档) ]  │
│    [添加存档] [移除选中] [上移] [下移]             │
├──────────────────────────────────────────────────┤
│ ② RimWorld 游戏目录(译中文标签用,可自动探测)     │
│    [D:\Steam\steamapps\common\RimWorld    ][浏览] │
│    ☑ 生成中文词典(首次扫描大 mod 集需几分钟)      │
├──────────────────────────────────────────────────┤
│ ③ 输出目录 [ …\output ]               [浏览…]     │
├──────────────────────────────────────────────────┤
│ 运行日志(解析统计、扫描进度…)                    │
│  [开始提取] [打开输出目录] ▓▓▓▓░░ 就绪            │
└──────────────────────────────────────────────────┘
```

同一殖民地的**中期档 + 终局档可以一起加入**:信件/台词窗口按各自覆盖的时间段合并去重,适合"存档被覆盖后从备份找回一段历史"的场景。

**命令行**(等价,亦可在无 GUI 环境跑):

```bash
python -m chronicle.pipeline output/ 存档A.rws 存档B.rws [--game-dir <RimWorld目录>] [--no-defs]
```

**打包成单文件 exe**:

```bash
pip install pyinstaller
pyinstaller build.spec      # → dist/RimworldChronicle.exe
```

## 支持范围与已知限制

- 按 RimWorld **1.6** 的 `.rws`(未压缩 XML)开发,对 1.5+ 的通用结构亦大概率可用;mod 数量不影响解析,只影响能解析出多少中文标签。
- 大存档(70 MB 级)解析耗时约 2~6 秒,全量 DOM 解析需要数百 MB 内存。
- 信件/消息/RimTalk 是游戏内的**环形缓冲**(只保留最近一段),更早的历史在存档被覆盖后即不可恢复——这是所有存档提取工具的共同边界。
- 依赖:仅 Python 标准库(tkinter / xml / json / tarfile)。不需要 Node,不需要联网,不读取 Steam 账号信息。

## 产出能到哪一步:示例摘录

用本项目导出的素材,我完成了 18 章的殖民地长篇《雪与教会》(全部设定可回溯到存档证据)。以下是成品小说的三段节选(作者基于私人存档的衍生创作,仅作展示):

> 后来人们问起风信子最早的事,她总是只说一句:"雪停了,我往外爬。"
>
> 再问,她就不说了。不是忘了,是不想换一种方式再失去一次。雪埋掉的东西,她不打算用嘴挖出来。
>
> ——《第一章 雪堆里的手》

> 到第三天,她想通了。……她盯着火光,一字一句:"我不该再这样落魄下去了。那些幸福,不该成为如今拘束我的锁链。也许我该去找我真正的未来。"这句话后来被教会档案原文誊走,题名叫《过去的和解》。
>
> ——《第十五章 长路归乡》(该段的情感锚点直接取自存档里的一手记录)

> 塔下是她的世界:八座据点的灯火散在大陆上,东一点,西一点,像撒在黑丝绒上的一把碎星。……雪要来,就让它来。教会已经不怕了。
>
> ——《第十八章 龙影的三十份肉食》
